# Elements of an NIH DMSP

NIH institutes, centers, or offices, may have specific data sharing expectations (e.g., scientific data to share, relevant standards, repository selection, timelines).

FAIR is encouraged.

Elements:
* Data Type
	* what will be generated or used:
		* type and amount/size
		* "type" - roughly, the 'kind' of instrument
		* e.g. "256-channel EEG data and fMRI images from ~50 research participants"
		* description details
		* data modality (imaging, genomic, mobile, survey)
		* level of aggregation (individual, aggregated, summarized)
		* degree of data processing
	* what will be preserved and shared
		* what metadata, other relevant data, and documentation will be included
		* provide rationale
* Related Types, Software, and/or Code
	* specialzed tools / software (names)
	* if applicable (how tools will be accessed)
		* (e.g., open source and freely available, generally available for a fee in the marketplace, available only from the research team)
		* whether tools will remain available
* Standards
	* consensus standards for data and metadata
	* many fields have and use common standards, others do not
* Data Preservation, Access, and Associated Timelines
	* name of repository
	* how will the data be findable and identifiable (persistent unique identifier or other indexing tools aka keywords)
	* when the data will be available and for how long
		* note differences if needed for different subsets of data
* Access, Distribution, or Reuse Considerations
	* expect researchers to maximize appropriate sharing
	* what factors affect access, distribution, reuse?
		* informed consent
		* privacy and confidentiality
			* consistency with local laws, regulations, policies
		* controlled access to repository
		* any other considerations
* Oversight of Data Management and Sharing
	* how will compliance with the plan be monitored and managed?
	* frequency
	* who?

# Allowable Costs

* costs must be during performance period, *even for data sharing beyond the award period*
* NO infrastructure costs that are institutional overhead (Facilities and Administrative costs)
* NO costs for collecting or accessing research data (routine costs of research, NOT data management and sharing)
* allowable costs
	* curating data and developing supporting documentation
		* formatting
		* de-identifying
		* preparing metadata
	* local data management considerations
		* unique and specialized infrastructure ofr local management and preservation (before depost into an established repository)
	* preserving and sharing in repositories
		* data deposit fees
		* if plan specifies X years, pay for X years prior to end of award period
